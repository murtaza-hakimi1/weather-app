🌦️ **Weather App**

A simple and responsive Weather App built with **HTML, CSS, JavaScript, and a Weather API**. It provides real-time weather information for different cities, including temperature, weather conditions, humidity, and wind speed. The app fetches live weather data from an external API and displays it in a clean, user-friendly interface.

**Technologies Used:** HTML5, CSS3, JavaScript, Weather API.

**Features:**
- Search for weather by city name
- Display real-time weather conditions
- Show temperature, humidity, and wind speed
- Dynamic weather information using API integration
- Responsive and user-friendly design
